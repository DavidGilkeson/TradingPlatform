# Project Atlas — Sprint 30.1 Risk Manager

The first Sprint 30 module adds risk-first paper-trade planning.

## Features

- maximum risk per trade
- stop-loss based position sizing
- portfolio exposure cap
- available cash validation
- take-profit planning
- reward/risk calculation
- minimum reward/risk warning
- pre-trade blockers and warnings

The module is deliberately introduced as a planner first. The next Sprint 30
step can enforce these rules directly inside the Paper Order Ticket.
