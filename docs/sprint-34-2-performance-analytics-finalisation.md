# Sprint 34.2 — Performance Analytics Finalisation

Sprint 34.2 turns the existing paper performance screen into an interpretation-focused review centre.

## Added
- Recent-vs-prior trade trend: Improving / Stable / Declining / Insufficient evidence.
- Ticker-level performance attribution: trades, wins/losses, win rate, net P&L, average/best/worst return.
- Risk-adjusted paper-account metrics: annualised return, annualised volatility, Sharpe, Sortino and Calmar.
- Clear early-evidence language so short paper-trading histories are not presented as reliable forecasts.
- Reorganised performance UI around: account results, improvement, risk, sources of P&L, daily/monthly and rolling performance.

All analytics are descriptive. They do not place, block, resize or recommend a paper trade.
